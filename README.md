# Демо-бот запису клієнтів

Готовий приклад для показу клієнтам: салонам краси, клінікам, майстерням тощо.
Клієнт обирає послугу → день → вільний час через кнопки. Ви (адміністратор)
одразу отримуєте сповіщення про кожен новий запис.

## Як налаштувати під конкретного клієнта

Відкрийте `bot.py`, знайдіть розділ `CONFIG` вгорі файлу — там усе, що
зазвичай треба змінити під клієнта:

```python
BUSINESS_NAME = "Салон краси «Демо»"

SERVICES = {
    "haircut": "Стрижка",
    "coloring": "Фарбування",
    "manicure": "Манікюр",
    "massage": "Масаж обличчя",
}

WORK_HOURS = list(range(9, 19))  # з 9:00 до 18:00
SLOT_MINUTES = 60                # крок між слотами
DAYS_AHEAD = 7                   # на скільки днів вперед показувати запис
```

Змініть назву бізнесу, список послуг і робочі години — і бот готовий під нового клієнта.

## Запуск (так само, як бот-нагадування)

1. Створіть бота через **@BotFather**, отримайте токен.
2. Дізнайтесь свій Telegram ID (наприклад, через бота **@userinfobot** — напишіть йому `/start`).
3. (Опційно, для AI-режиму) Отримайте ключ на **console.anthropic.com** → API Keys.
4. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустіть:
   ```bash
   export TELEGRAM_BOT_TOKEN="токен_від_BotFather"
   export ADMIN_CHAT_ID="ваш_telegram_id"
   export ANTHROPIC_API_KEY="ваш_ключ_anthropic"   # опційно — вмикає AI-запис вільним текстом
   python bot.py
   ```

## AI-запис вільним текстом

Якщо задано `ANTHROPIC_API_KEY`, клієнт може писати боту звичайною мовою в приватному чаті —
наприклад «хочу підстригтись у суботу зранку» — і бот сам визначить послугу, дату й час
та оформить запис (або перепитає деталі, якщо чогось не вистачає). Кнопковий `/book`
продовжує працювати незалежно — це запасний варіант, якщо AI недоступний або клієнт
віддає перевагу кнопкам.

Без `ANTHROPIC_API_KEY` бот просто ігнорує вільний текст і працює лише через команди й кнопки.

## Розгортання на Railway

Той самий процес, що й для бота-нагадування:
1. Завантажте всі файли (`bot.py`, `requirements.txt`, `Procfile`) в новий репозиторій на GitHub.
2. Створіть новий проєкт на Railway → Deploy from GitHub repo.
3. Додайте змінні середовища: `TELEGRAM_BOT_TOKEN`, `ADMIN_CHAT_ID` і (опційно) `ANTHROPIC_API_KEY`.
4. Перевірте логи — має з'явитися рядок «Бот запису запущено.».

## Команди бота

| Команда | Що робить |
|---|---|
| `/start` | Привітання |
| `/book` | Почати запис — вибір послуги, дня, часу |
| `/mybookings` | Переглянути свої активні записи |
| `/cancel <id>` | Скасувати запис |
| `/help` | Довідка |

## Що можна додати далі (для продажу дорожче)

- Нагадування клієнту за день до візиту (можна перевикористати логіку з бота-нагадування)
- Різна тривалість послуг і автоматичний розрахунок зайнятих слотів
- Кілька майстрів/спеціалістів на вибір
- Інтеграція з Google Calendar чи Google Sheets для власника бізнесу
- Оплата передоплати через Telegram Payments
